# مِشْكَاة (Mishkah) — المنصة التعليمية التفاعلية متعددة المستويات
# Mishkah — Multi-Level Interactive Educational & Book Analytics Platform

منصة تعليمية تفاعلية متكاملة ثنائية اللغة (العربية RTL / الإنجليزية LTR) لتحويل الكتب والمحتوى المعرفي والثقافي إلى دروس تفاعلية موزعة على **3 مستويات تعليمية** (مبتدئ، متوسط، متقدم) مع نظام مصادقة آمن، ولوحة تحكم تحليلية لمراقبة أداء الطلاب، وتنبيهات ذكية، ونظام إدارة محتوى (CMS).

---

## 1. تحليل الكتاب وهيكلة المستويات الثلاثة (Book Content Analysis & 3-Level Taxonomy)

يرتكز التطبيق على **كتاب مِشْكَاة المعرفة والبيان: أصول الفكر المنهجي والبلاغة التطبيقية**، وقد تم استخراج بنيته وتصنيفه وفق معايير تربوية دقيقة:

| المستوى | الاسم بالعربية | English Level | معيار التصنيف التربوي |
| :--- | :--- | :--- | :--- |
| **المستوى الأول** | **مبتدئ (التأسيس)** | **Beginner** | ضبط المفاهيم الأساسية، التعريفات الأولية، التمييز بين المصطلحات، والأمثلة التوضيحية المباشرة. |
| **المستوى الثاني** | **متوسط (التطبيق)** | **Intermediate** | الربط بين المفاهيم، بناء الحجج القياسية، تحليل التراكيب البلاغية، وتطبيق القواعد على نصوص متنوعة. |
| **المستوى الثالث** | **متقدم (الاستنباط والنقد)** | **Advanced** | التفكيك النقدي، الموازنة بين المذاهب، كشف المغالطات الخفية، والتركيب الإبداعي المستقل. |

كما يتضمن التطبيق **محرك تحليل الكتب والمستندات (`BookContentAnalyzer`)** الذي يسمح باستيراد أي ملف نصي (`.txt` / `.md`) أو لصق محتوى كتاب كامل ليقوم تلقائياً بتقسيمه إلى فصول، مفاهيم، أمثلة، وأسئلة مع تصنيفها إلى المستويات الثلاثة.

## 2. نظام التسجيل والمصادقة والأدوار (Authentication & Role-Based Access)

- **تشفير كلمات المرور:** استخدام خوارزمية `PBKDF2WithHmacSHA256` مع Salt عشوائي آمن (`SecurityUtils`).
- **إدارة الجلسات:** توليد رمز جلسة موقّع (`HMAC-SHA256 JWT Session Token`) مع حفظ حالة الجلسة.
- **الأدوار المدعومة (RBAC):**
  - **طالب (Student):** دراسة الفصول والدروس، خوض الاختبارات التفاعلية، ومراجعة لوحة أدائه الشخصية.
  - **معلم / مشرف (Instructor):** مراقبة أداء جميع الطلاب على المستويات الثلاثة، استعراض التنبيهات الذكية، وتصدير التقارير.
  - **مدير النظام (Admin):** صلاحيات كاملة لإدارة المحتوى (إضافة/تعديل/حذف الدروس والأسئلة) وتحليل الكتب الجديدة.
- **الحسابات التجريبية الجاهزة (كلمة المرور الموحدة: `Mishkah@2025`):**
  - طالب: `student@mishkah.edu`
  - معلم/مشرف: `instructor@mishkah.edu`
  - مدير النظام: `admin@mishkah.edu`

## 3. مراقبة أداء الطالب على 3 مستويات (3-Level Student Analytics Dashboard)

- **مؤشرات الأداء المتتبعة:** نسبة الإنجاز، الوقت المستغرق، الدرجات، عدد المحاولات، والأخطاء المتكررة في كل مستوى.
- **الرسوم البيانية التفاعلية (`AnalyticsCharts`):**
  - **Bar Chart:** مقارنة الإنجاز والدرجات عبر المستويات الثلاثة (مبتدئ / متوسط / متقدم).
  - **Line Chart:** منحنى تطور درجات الطالب عبر المحاولات المتتالية.
  - **Radar Chart:** بصمة الكفاءة المعرفية عبر 5 مهارات (استيعاب المفاهيم، الاستدلال المنطقي، التذوق البلاغي، التحليل النقدي، التركيب التطبيقي).
- **نظام التنبيهات الذكي:** يرصد تلقائياً تعثر الطالب (انخفاض الدرجة عن 65%، أو تراجع الأداء بين المحاولات، أو تكرار الأخطاء في مهارة محددة) ويوجه تنبيهاً للمعلم والطالب.
- **تصدير التقارير:** تصدير فوري لتقارير الأداء بصيغتي **PDF** و **CSV** (`ReportExporter`).

## 4. البنية المعمارية للمشروع (Clean Modular Architecture)

```text
app/src/main/
├── assets/i18n/
│   ├── ar.json                       # قاموس الترجمة العربية (RTL)
│   └── en.json                       # قاموس الترجمة الإنجليزية (LTR)
└── java/com/example/
    ├── MainActivity.kt               # نقطة الدخول وتهيئة قاعدة البيانات
    ├── data/
    │   ├── Entities.kt               # كيانات قاعدة البيانات (Room Entities)
    │   ├── MishkahDao.kt             # واجهة الاستعلامات التدفقية (Flow DAO)
    │   ├── MishkahDatabase.kt        # قاعدة بيانات Room المحلية
    │   ├── MishkahRepository.kt      # مستودع إدارة الأعمال والتنبيهات الذكية
    │   ├── SecurityUtils.kt          # تشفير كلمات المرور وتوليد رموز الجلسات
    │   └── SeedData.kt               # المحتوى التعليمي الكامل للكتاب والبيانات الأولية
    ├── domain/
    │   ├── BookContentAnalyzer.kt    # محرك تحليل الكتب وتصنيفها إلى 3 مستويات
    │   └── ReportExporter.kt         # محرك تصدير التقارير بصيغتي PDF و CSV
    ├── i18n/
    │   └── AppI18n.kt                # نظام التبديل الفوري بين العربية والإنجليزية (RTL/LTR)
    └── ui/
        ├── MishkahApp.kt             # الهيكل المتجاوب وشريط التنقل والتبديل اللغوي
        ├── MishkahViewModel.kt       # إدارة الحالة التفاعلية (StateFlow)
        ├── components/
        │   └── AnalyticsCharts.kt    # الرسوم البيانية (Bar, Line, Radar)
        ├── screens/
        │   ├── AuthScreen.kt                 # شاشة الدخول والتسجيل واستعادة كلمة المرور
        │   ├── CurriculumScreen.kt           # شاشة الفصول والدروس والاختبارات التفاعلية
        │   ├── AnalyticsDashboardScreen.kt   # لوحة مراقبة أداء الطلاب والتقارير
        │   └── BookAnalyzerAndCmsScreen.kt   # محلل الكتب ولوحة إدارة المحتوى (CMS)
        └── theme/
            ├── Color.kt              # الهوية البصرية الفاخرة (الذهبي والزمردي والكحلي الداكن)
            ├── Type.kt               # الخطوط العربية واللاتينية (Amiri & Cairo)
            └── Theme.kt              # نظام الألوان الداكن والفاتح
```

## 5. إضافة أو تعديل الدروس واللغات

1. **إضافة أو تعديل درس بدون تعديل الكود:**
   - افتح تبويب **إدارة المحتوى (CMS)** من الحساب الإداري أو حساب المعلم.
   - اختر الفصل والمستوى التعليمي (مبتدئ / متوسط / متقدم)، وأدخل عنوان الدرس وشرحه والمفاهيم والأمثلة باللغتين العربية والإنجليزية، ثم اضغط **حفظ الدرس**.
2. **استيراد كتاب جديد:**
   - افتح تبويب **محلل الكتب (Book Analyzer)**، ثم ارفع ملف نصي (`.txt` / `.md`) أو الصق محتوى الكتاب، واضغط **تحليل الكتاب وتوليد المستويات الثلاثة**.
3. **إضافة لغة جديدة:**
   - أضف ملف ترجمة جديد في `app/src/main/assets/i18n/` وعرّف القيم المقابلة في `AppI18n.kt`.
